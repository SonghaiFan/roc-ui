Install for your agent

Download and extract the ZIP. Place its responsive-object-continuity folder in your agent's skill directory. It contains the instructions, cases, references and license; the gallery and its dependencies are separate.

For a local ROC checkout, link the canonical source:

npm run skill:link
# Or choose your agent's destination:
npm run skill:link -- /path/to/agent/skills/responsive-object-continuity

The link command keeps an existing unrelated destination untouched. Skill installation does not require installing the gallery's npm dependencies.
